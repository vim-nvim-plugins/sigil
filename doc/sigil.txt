*sigil.txt*  Variable panel for Vim — 21 languages, one tree-sitter parser

==============================================================================
COMMANDS                                                       *sigil-commands*

:Sigil          Open / refresh the variable panel for the current file
:SigilX     	Close the panel. Same as :Sigil close
:SigilR   		Rename the variable under the cursor, in its own scope only.
			Other variables with the same name, members (obj.name),
			strings and comments are left alone. On a name sigil does
			not track (a function, a builtin) it renames every whole
			word in the file. On a variable it knows but can't tie to
			this spot (obj.name outside its class) it renames nothing
			and points to the panel. Same as :Sigil rename

==============================================================================
KEYBINDINGS                                                       *sigil-keys*

Panel: ~
  <Enter>   Jump to first occurrence, close panel
  o         Jump, keep panel open
  n / p     Cycle occurrences
  r         Rename the selected row's variable (every line it lists)
  /         Filter (type to narrow)
  <Esc>     Clear filter
  q         Close panel

Source window: ~
  <leader>s   Open / refresh panel
  <leader>n   Next occurrence of word under cursor
  <leader>p   Previous occurrence
  <leader>r   Rename variable under cursor (as :SigilR)

==============================================================================
CONFIGURATION                                                  *sigil-config*

g:sigil_height    Panel height in lines (default: 12)
g:sigil_binary    Path to the helper (default: bin/sigil inside the plugin)

Example: >
    let g:sigil_height = 15
<
==============================================================================
LANGUAGES                                                    *sigil-languages*

Every language goes through the same helper, bin/sigil: tree-sitter parses
the file and that language's locals query (from nvim-treesitter) marks
scopes, definitions and uses. Each use is matched to the nearest definition
of the same name, so the panel lists every line a variable occurs on.

Contexts: global, local, param, field. `self.x`, `this.x`, `@x` count as uses
of the field x of the class they are in.

Get the helper once. Prebuilt for Linux and macOS (needs make, curl): >
    cd <plugin dir> && make download
<
Or build it (also needs a C compiler and tar): >
    cd <plugin dir> && make
<
With vim-plug: >
    Plug 'vim-nvim-plugins/sigil', { 'do': 'make download || make' }
<
Supported: Bash, C, C#, C++, Go, Java, JavaScript (+JSX), Julia, Kotlin, Lua,
OCaml, Pascal, PHP, Python, R, Ruby, Rust, TSX, TypeScript, Vim script, Zig.
`bin/sigil --list` prints each language with the filetypes it covers.

The language comes from the buffer's 'filetype', or the file extension when
'filetype' is empty.

==============================================================================
OUTSIDE VIM                                                      *sigil-cli*

The helper runs on its own: >
    bin/sigil <language|extension> <file>
    bin/sigil --scopes <language|extension> <file>
    bin/sigil --positions <language|extension> <file>
<
Output is one variable per line: context|name|line,line,...
--scopes keeps same-named variables in different scopes apart and appends
the scope's line range (|first-last). --positions is --scopes with every
occurrence as line:col (byte column, 1-based); :SigilR uses it. SKILL.md in the plugin directory
describes the same for AI agents.
